应用HLS直播流下载支持说明
## 中文说明
本应用支持HLS直播流文件的下载与保存，目前不支持LLHLS以及需要校验登录状态的直播网站。
## English Description
This application supports the download and saving of HLS live stream files. Currently, it does not support LLHLS and live streaming websites that require login verification.
### 补充说明 / Supplementary Notes
- HLS：HTTP Live Streaming，是一种基于HTTP的流媒体传输协议，广泛用于直播场景。
- HLS: HTTP Live Streaming, a streaming media transmission protocol based on HTTP, widely used in live streaming scenarios.
- LLHLS：Low-Latency HLS，低延迟HLS协议，目前暂未支持。
- LLHLS: Low-Latency HLS, a low-latency HLS protocol, which is not supported at present.
- 需校验登录状态的直播网站：指需要用户登录账号并通过身份验证后，才能访问和观看直播的平台，此类网站暂不支持下载。
- Live streaming websites requiring login verification: refers to platforms that require users to log in to their accounts and pass identity verification before accessing and watching live streams. Downloading from such websites is not supported for the time being.
